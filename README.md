# Acadia 30

A tracker for the Acadia National Park Full 30 Peak Challenge (Peakery's list).

- Comparative heights chart, in the style of Johnson's 1860s mountain charts, sortable by height or grouped by outing
- Topographic map (USGS The National Map, or OpenTopoMap) with every summit and the Acadirettissima traverse
- Rankings by elevation and prominence, nine suggested outings, and a check-off list with summit dates

It's a single static page with no build step, no server and no tracking. Checkmarks are saved only in each visitor's own browser.
